# Capturas de las aplicaciones

Sube las capturas en formato PNG usando exactamente estos nombres. Las fichas web ya tienen las rutas preparadas: al publicar los archivos, las imágenes aparecerán automáticamente sin editar el HTML.

## N3mesis Launcher (Windows, horizontal)
Carpeta: `assets/screenshots/launcher/`

- `launcher-home.png` — Inicio
- `launcher-instances.png` — Instancias
- `launcher-modrinth.png` — Modrinth
- `launcher-settings.png` — Ajustes

Formato recomendado: 16:9 (1920×1080 o 1600×900).

## Party (móvil, vertical)
Carpeta: `assets/screenshots/party/`

- `party-home.png` — Inicio
- `party-games.png` — Juegos
- `party-camera.png` — Cámara
- `party-plans.png` — Planes

Formato recomendado: vertical 9:16 (por ejemplo 1080×1920).

## Nexo (móvil, vertical)
Carpeta: `assets/screenshots/nexo/`

- `nexo-contacts.png` — Contactos
- `nexo-detail.png` — Detalle de contacto
- `nexo-collections.png` — Colecciones
- `nexo-settings.png` — Ajustes

Formato recomendado: vertical 9:16 (por ejemplo 1080×1920).

Puedes subir primero solo algunas imágenes. Las que falten conservarán su marcador de captura pendiente.
