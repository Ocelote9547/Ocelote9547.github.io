# N3mesis Studio — web

Web estática responsive creada con HTML, CSS y JavaScript. No necesita frameworks ni compilación.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: diseño adaptable a móvil y escritorio.
- `script.js`: menú móvil y año automático.
- `assets/`: icono y recursos gráficos.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado exactamente `Ocelote9547.github.io`.
2. Sube el contenido de esta carpeta a la raíz del repositorio (no subas solo el ZIP).
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
5. Espera a que termine la publicación. La web debería estar en `https://ocelote9547.github.io/`.

## Personalizar proyectos
Los estados de Party, Nexo y Utils están redactados según la información disponible al crear esta plantilla. Actualiza descripciones, estados y enlaces cuando cada proyecto esté publicado. No se han inventado enlaces para Party ni Utils.

Para añadir capturas reales, guarda los archivos en `assets/` y sustituye los bloques visuales de demostración de cada tarjeta por etiquetas `<img>` con rutas locales. Usa imágenes propias de cada aplicación.
